---
title: Letterboxd
description: Import and sync Letterboxd watchlists and ratings into Seedarr.
---

Connect Letterboxd from **Settings → Modules** (Social) and/or your **user profile**.

Install the Letterboxd module to enable the integration, then import or sync from your profile.

## Import

1. Export your data from Letterboxd (zip archive from Letterboxd settings).
2. Open your Seedarr profile.
3. Use **Letterboxd → Import** and drop the zip (size limit applies).
4. Seedarr imports rated/watched films and enriches them via TMDB (duration, categories, ratings).

## Sync

After a username is linked, use **Sync** to refresh:

- New ratings
- Newly watched films
- Updates to existing entries

## What you get

- Letterboxd taste reflected in Seedarr (watchlist / history style data depending on export contents)
- TMDB-backed metadata so titles match the in-app catalog
- Faster personalization for likes and “what to watch next”

## Tips

- Re-import if a sync looks incomplete after a large Letterboxd backlog.
- Letterboxd username is stored on your user profile — keep it up to date if you rename the account.
- Import is per user; each household member can connect their own Letterboxd.
